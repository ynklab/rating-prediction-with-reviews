# Enhancing Rating Prediction with Off-the-Shelf LLMs Using In-Context User Reviews
This repository contains data and code for the paper "Enhancing Rating Prediction with Off-the-Shelf LLMs Using In-Context User Reviews".

## Setup
The behavior is verified on Python 3.11.10.

```bash
pip install -r requirements.txt
```

## Directory Structure

This repository has the following directory structure:
```
rating-prediction-with-reviews/
│── src/ # Contains the source code
│── data/ # Contains datasets
```

The datasets are downloaded from the following sources and formatted as needed:
- [Per-MPST](https://github.com/facebookresearch/PerSE)
- [Recipe](https://www.kaggle.com/datasets/shuyangli94/food-com-recipes-and-user-interactions)
- [Books](https://amazon-reviews-2023.github.io/)
- [TL;DR](https://openaipublic.blob.core.windows.net/summarize-from-feedback/website/index.html#/)

## How to Use

### Main Script

Predict the ratings using the following command:

```bash
python src/main.py --model [MODEL] --dataset [DATASET] --mode [IN-CONTEXT-DATA]
```

- `MODEL`: The name of the model to use. Options include `gpt-3.5-turbo`, `gpt-4`, `claude-2`, etc.
- `DATASET`: The dataset to use. Options include `permpst`, `recipe`, `books`... etc.
- `IN-CONTEXT-DATA`: The type of in-context data to use. Options:
    - `noreview`: No in-context review text is provided.
    - `readreview`: In-context review text is provided, but the model is just instructed to predict the score
    - `original`: In-context review text is provided, and the model is instructed to write a new hypothetical review and predict the score based on that.
    - `cot`, `ps`, `kar`, `kar-llmrec`, `scoresumm`: Variants of `original` with different prompt styles.
    - `user-profile`, `user-profile-readreview`, `user-profile-noreview`, `user-profile-noicl`: In addition to the different in-context data, "self-described preference" style data generated by LLMs is provided as well.

The script creates an output CSV file at `outputs/[EXP_ID]/raw_output.csv`. The raw output CSV contains the following columns:
- `prompt`: The prompt sent to the LLM to generate the response.
- `raw_response` The raw text response from the LLM.
- `label_score`: The ground truth score.
- ... etc

### Self-described Preference Generation

If you run the main script with `user-profile-*` mode, you need to generate the self-described preference data first. You can do this by running:

```bash
python src/generate_self_described_preferences.py --model [MODEL] --dataset [DATASET]
```

### Postprocessing

You can postprocess the raw output CSV to extract the predicted scores and compute evaluation metrics by running:

```bash
python postprocess.py --output-path [OUTPUT-PATH]
```

`OUTPUT-PATH` should be the path to the output directory created by the main script, e.g., `outputs/[EXP_ID]`.

Two additional files will be generated in the output directory:
- `processed_output.csv`: Contains the extracted predicted scores along with the ground truth scores.
- `output_stats.json`: Contains evaluation metrics such as RMSE, correlation coefficients, etc.
